# Mobile-Sales-Analysis-Dashboard-
Interactive Power BI dashboard for analyzing mobile sales performance, transactions, customer ratings, payment methods, brands, models and city-wise sales trends.
Project Overview

This project presents an interactive Power BI dashboard to analyse mobile sales performance, transaction trends, customer ratings, and payment methods.

Tools Used:

Microsoft Power BI
Data Visualization
Interactive Dashboard Design
Dashboard Screenshot

Key Insights:

Analyse total mobile sales and transaction performance.
Explore sales trends across different time periods.
Compare customer ratings and payment methods.
Understand sales distribution across mobile models and brands.

The Power BI dashboard file (.pbix) is available in this repository.
